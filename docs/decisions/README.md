# Decisions

Short notes on **why** we chose something, so nobody (human or AI) undoes it by accident. The big picture lives in [PLAN.md](../../PLAN.md); this folder is for smaller decisions made while building.

Name files `NNNN-short-title.md` (e.g. `0001-meilisearch-for-search.md`), using this format:

```md
# NNNN: Title
Date: YYYY-MM-DD · Status: accepted | replaced by NNNN

## Context
What problem or choice we faced.

## Decision
What we chose.

## Why
Reasons, and the options we rejected.

## Consequences
What this makes easier or harder.
```
