# Design

Source material and rules for the Waaree CMS design system.

- `screenshots/`: screenshots of Waaree's existing pages, named `<page>-<desktop|mobile>.png`.
- `design-rules.md` (to be written from the screenshots): colors, fonts, spacing, radius, shadows, imagery and tone. These rules become the tokens in `waaree-web/src/styles/tokens.css`.

**Status:** design rules extracted ([design-rules.md](design-rules.md)) from waaree.com's CSS + 4 screenshots (home hero, blog listing, events listing, investor documents). Tokens are live in `tokens.css`.

**Target feel:** minimal, modern, calm, new-age (design language v2: design-rules.md §8). Lots of whitespace, crisp type, soft depth, smooth micro-motion. Light + dark mode. WCAG 2.2 AA contrast.
